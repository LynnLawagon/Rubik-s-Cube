# Rubik's Cube

A lightweight browser-based Rubik's Cube simulation built with HTML, CSS, and JavaScript.

## Features

- Interactive 3D cube view
- Drag to orbit and twist layers
- Scramble and reset controls
- Move counter and timer
- Auto-solved detection banner

```

## Files

- `index.html` – page structure
- `style.css` – interface styling
- `script.js` – cube logic and interaction

## Notes

This project uses the browser's WebGL capabilities through Three.js from the project HTML includes, so it works best in a modern browser.
